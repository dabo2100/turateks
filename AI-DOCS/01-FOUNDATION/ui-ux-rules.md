# UI / UX Rules

- Language: **Turkish** UI strings.
- Colors from tokens (logo): orange `#F58220`, charcoal `#333333`, copper `#A65E2E`, silver `#A7A9AC`, bg `#FFFFFF` / `#F6F6F6`.
- Logo: official file only (from WP uploads `LogoTura-1.png` or successor). No generated hexagon.
- shadcn/ui primitives. Do not add another UI kit.
- Product cards: image, badges (`Toptan`, `Yeni`), tags, SKU, **den ₺** price.
- Desktop card hover: cycle extra angles when images exist.
- PDP: Add to cart disabled until required variants selected.
- Motion: short, opacity/transform. No looping hero circus.
- Toasts: Sonner.
- Touch targets ≥ 44px on mobile checkout.
