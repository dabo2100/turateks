# Feature Brief — Admin dashboard

## Summary

Simple owner panel after storefront works. Direct screens: products, orders, pages, blog, settings. Not WooCommerce.

## In scope

- Auth gate `admin`
- Products + variants + tiers + images
- Orders list/status
- Pages/blog
- Settings (tax, NAP, PayTR env already on server)
- Clear forms, Sonner, tables (Chart.js only if a real chart is requested)

## Out of scope

- Multi-admin RBAC beyond owner
- POS / KDS
- Theme customizer
- Phase 8 starts only after Phase 5–7 storefront is usable
