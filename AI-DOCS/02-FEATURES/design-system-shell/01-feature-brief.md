# Feature Brief — Design system & shell

## Summary

Shared visual system and chrome for the storefront: tokens, typography, logo, header, footer, WhatsApp FAB. Matches Figma Make (orange + charcoal) and the **official logo file**.

## In scope

- CSS variables / Tailwind theme
- shadcn setup
- Header + mobile nav + footer
- Home page **structure** (hero, category strip, featured grid placeholders)
- 404 layout using the same chrome

## Out of scope

- Real product data
- Admin theme
- Full blog/CMS pages
- Animations beyond Motion hover/fade

## WordPress note

Copy logo from `../app/public/wp-content/uploads/2024/08/LogoTura-1.png` (or current official file). Do not invent a mark.
