# Feature Brief — Wholesale pricing

## Summary

Quantity bands (kademe) owned by the dashboard. PDP table + `/toptan` landing. Same SKU, better unit price at higher qty.

## In scope

- Data model: product has ordered minQty→maxQty→unitPrice rows
- `/toptan` page (Figma wholesale band)
- Cart line uses the tier for **that line qty**

## Out of scope

- Separate wholesale login / B2B portal
- Per-customer private price lists (unless later decision)
