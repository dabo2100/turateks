# Feature Brief — CMS & legal pages

## Summary

Owner-editable pages: Hakkımızda, İletişim, KVKK, Mesafeli Satış, İade, Ön Bilgilendirme. Optional “print on invoice”.

## In scope

- Page model (slug, title, body, seo)
- Storefront render
- Contact form + map placeholder
- Invoice-include flag (settings)

## Out of scope

- Visual page builder
- WP Gutenberg
