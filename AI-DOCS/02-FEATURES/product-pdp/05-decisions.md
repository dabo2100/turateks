# Decisions — Product PDP

### PD-DEC-01
- **Status:** Approved
- **Decision:** One product URL. Tiers change price, they do not create a second product.

### PD-DEC-02
- **Status:** Approved
- **Decision:** Variants are open-ended (owner-defined), not hardcoded S–3XL only — UI must allow N sizes/colors.

### PD-DEC-03
- **Status:** Approved
- **Decision:** Qty control is steppers **plus** a free-typed numeric field (`inputMode=numeric`, non-digits stripped). No letter entry on mobile or desktop.

### PD-DEC-04
- **Status:** Approved
- **Decision:** PDP visual language follows a modern minimal commerce layout (vertical thumbs, charcoal CTAs/size selected state) while keeping Turateks orange for active tier/price accents. Reviews/wishlist out of scope.

### PD-DEC-05
- **Status:** Approved
- **Decision:** Long product copy lives in tabs below the buy box (Detaylar / Malzeme / Beden & Kesim / Kargo & İade). The purchase column only shows identity + pricing + variants + qty + CTAs.
