# Feature Brief — Product PDP

## Summary

`/urunler/[slug]`: gallery, tags, SKU, description, wholesale table, color swatches, sizes, qty, live unit price, add to cart, WhatsApp quote.

## In scope

- Gallery + thumbs (angles)
- Required variant selection
- Qty stepper updates unit price from tiers
- Specs table
- Related products (optional if data exists)

## Out of scope

- PayTR
- Admin product editor
- Reviews import from WP
