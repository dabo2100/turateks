# Feature Brief — PayTR gateway

## Summary

Same merchant flow as WooCommerce PayTR iframe. Server token, client payment, hash-verified callback, order `paid`.

## In scope

- Token create (server)
- Embed or hosted page as WP did
- Callback + success / fail pages
- Logging without secrets

## Out of scope

- New PSPs
- Storing raw card data
- Keys in git or markdown
