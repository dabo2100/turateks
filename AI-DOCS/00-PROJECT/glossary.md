# Glossary

| Term | Meaning |
|-------|---------|
| **Storefront** | Public site customers see |
| **Admin / Dashboard** | Owner panel (`/admin`) |
| **PDP** | Product detail page |
| **Variant** | Combination such as color + size with its own price/SKU/stock |
| **Tier / kademe** | Quantity band → unit price (e.g. 1–9, 10–49, 50+) |
| **Toptan** | Wholesale; same product, better unit price at higher qty |
| **NAP** | Name, address, phone (and email) — one source in settings |
| **Seed** | Import from WordPress into Prisma |
| **301 map** | Old WP URL → new Next URL |
| **Owner** | Client who will use the dashboard |
